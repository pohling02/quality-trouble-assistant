# Boot loop after an OS update

Category: Boot

## Symptoms
- Device restarts again and again during or right after an update
- Update never reaches the login screen

## Cause
A partial or corrupted update, or a startup component that crashes during boot.

## Fix
1. Enter recovery mode
2. Use startup repair or uninstall the latest update
3. Run a file system check and a system file check
4. If it still fails, restore from a snapshot or reinstall while keeping data
