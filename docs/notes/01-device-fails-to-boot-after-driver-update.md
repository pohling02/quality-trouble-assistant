# Device fails to boot after driver update

Category: Boot

## Symptoms
- Screen stays black or the logo hangs after a driver update
- Device reboots repeatedly

## Cause
The new driver (often GPU or storage) is incompatible with the OS version or firmware.

## Fix
1. Boot into recovery or safe mode
2. Roll back or uninstall the latest driver
3. Install the driver version recommended by the hardware vendor
4. Reboot normally and pause automatic driver updates until verified
