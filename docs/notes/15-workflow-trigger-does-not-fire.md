# Workflow trigger does not fire

Category: Workflow

## Symptoms
- No runs appear in the history after the event

## Cause
The flow is turned off, the connection is broken, the trigger condition is wrong, or the event source changed.

## Fix
1. Confirm the flow is turned on
2. Check connections for errors
3. Test the trigger condition with sample data
4. Save and re-enable the flow, then trigger the event again
