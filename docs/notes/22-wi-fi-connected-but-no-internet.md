# Wi-Fi connected but no internet

Category: Network

## Symptoms
- Network icon shows connected but pages do not load

## Cause
DNS failure, a captive portal that needs login, or a wrong gateway or IP configuration.

## Fix
1. Ping an IP address such as 8.8.8.8 and then a hostname
2. If only the hostname fails, change or flush DNS
3. Open a browser to complete any captive portal login
4. Renew the IP lease or restart the network adapter
