# No bootable device found

Category: Boot

## Symptoms
- Firmware shows 'no bootable device' or 'operating system not found'

## Cause
Wrong boot order, a disconnected or failing disk, or a damaged bootloader.

## Fix
1. Enter firmware setup and confirm the disk is detected
2. Set the correct boot device first
3. Check cables or reseat the drive
4. Repair the bootloader from installation media
